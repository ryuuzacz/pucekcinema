# PucekCinema – Kodi repozitář

Repozitář pro instalaci a automatické aktualizace Kodi doplňku PucekCinema (frontend pro Jellyfin).

1. Kodi → Nastavení → Systém → Doplňky → povolit **Neznámé zdroje**.
2. Doplňky → Instalovat ze ZIP souboru →
   [`repository.pucekcinema/repository.pucekcinema-1.6.zip`](repository.pucekcinema/repository.pucekcinema-1.6.zip).
3. Doplňky → Instalovat z repozitáře → PucekCinema repozitář → Video doplňky → PucekCinema.

Kodi pak nové verze stahuje a instaluje automaticky.

Volitelně vzhled **PucekCinema** (Kodi 21): Doplňky → Instalovat z repozitáře → PucekCinema repozitář →
Vzhled → PucekCinema. Je to Estuary, jehož úvodní obrazovku tvoří knihovny z Jellyfinu s řadami
Pokračovat ve sledování, Naposledy přidané a další.
